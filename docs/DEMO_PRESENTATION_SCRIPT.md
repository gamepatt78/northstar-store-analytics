# Northstar Store Analytics — Demo Presentation Script

This script is part of the project documentation in the `docs` folder.
## Before recording

- Open the live app: <https://infozatech-analytics.web.app>
- Sign in with your demo account before starting the recording.
- Use a browser window large enough to show the dashboard clearly.
- Do not show your password, inbox, Firebase reset link, or private account details.
- The dashboard uses illustrative sample store data; it is not connected to a real shop.

## Opening

“Hello, I’m Athwin. I’m going to demonstrate Northstar Store Analytics, a responsive dashboard designed to make retail performance easier to understand. It brings key sales metrics, interactive charts, order activity, and product rankings together in one place.”

## Sign-in

“Users can securely create an account and sign in with Firebase Authentication. If someone forgets their password, they can request a reset email and follow its secure link to choose a new password.”

*If you do not want to demonstrate authentication, sign in before recording and start the video at the dashboard.*

## Dashboard overview

“At the top are four summary cards: gross sales, orders placed, unique customers, and average order value. They provide a quick snapshot of the selected store and date range.”

“The filters let us narrow the dashboard by date, category, region, and order status. I’ll change the date range here. The metrics and visualizations update to reflect the selected period.”

## Charts and orders

“The sales chart shows revenue over time. The order-pulse chart summarizes fulfillment status, while the regional chart compares order activity across markets. The category chart gives another view of the sales mix.”

“Below the charts, the recent-orders table makes it easier to scan customer orders, products, regions, status, and totals. Product leaders highlight which items are selling most in the selected view.”

## Store selector and display

“The store selector switches between the example storefronts. The dashboard also supports a dark theme, which can be changed using the theme control while viewing the dashboard.”

## Closing

“Northstar is built with React and Vite, with Recharts for the visualizations and Firebase Authentication for account access. The current dashboard data is illustrative sample data, so connecting a real store or database would be a future integration. Thank you for watching.”
